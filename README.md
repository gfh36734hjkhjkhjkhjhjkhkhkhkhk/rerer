# Prism

Удобная программа для Windows, которая включает обход блокировок Discord и YouTube, прокси для Telegram, режим для игр и доступ к нейросетям. Всё главное на одном экране: круглая кнопка включения, проверка Discord и YouTube и автозапуск вместе с Windows. Окно только чёрное с белым, без лишнего.

## Скачать

Откройте раздел [Releases](../../releases/latest) и скачайте:

- **Prism-…-setup.exe** — установщик, рекомендуется;
- **Prism-…-portable.zip** — без установки: распакуйте архив и запустите `Prism.exe`.

Программа просит права администратора: без них обход блокировок в Windows не работает.

## Как пользоваться

1. Нажмите круглую кнопку на главной. Когда обход заработает, вокруг кнопки загорится кольцо, а справа будет видно, открываются ли Discord и YouTube и с какой задержкой.
2. Если написано «Не открывается», нажмите «Подобрать». Prism проверит все стратегии и включит самую быструю. Выбрать стратегию вручную можно кнопкой «Выбрать».
3. Telegram, режим для игр и нейросети включаются справа. Чтобы подключить Telegram, включите его и нажмите «Добавить в Telegram».
4. Включите «Автозапуск», и Prism будет запускаться вместе с Windows: в трее, без окна и сразу с включённым обходом. Включать и выключать обход можно прямо из меню значка в трее.
5. Если какой-то сайт не открывается, добавьте его в разделе «Сайты». Можно вставить сразу несколько адресов, русские домены (например, `сайт.рф`) тоже подходят. Журнал, диагностика и обновления находятся в «Настройках».

## Если обход не работает

1. Нажмите «Подобрать» на главной. Если не подойдёт ни одна стратегия, Prism вернёт прежнюю и подскажет, что делать дальше.
2. Откройте «Настройки» → «Диагностика» и нажмите «Проверить». Prism найдёт то, что чаще всего мешает обходу: выключенную службу базовой фильтрации (BFE), другие обходы (GoodbyeDPI, служба zapret), Killer, Intel Connectivity Network Service, Check Point, SmartByte, VPN, Adguard, системный прокси, записи YouTube в файле hosts и файлы, которые удалил антивирус. Часть проблем исправляется кнопкой «Исправить».
3. Если `winws.exe` закроется сам (например, после сна компьютера или из-за антивируса), Prism перезапустит обход, но не чаще трёх раз за 10 минут. Если стратегия падает сразу после запуска, Prism не перезапускает её по кругу и предлагает выбрать другую.
4. Если ничего не помогло, напишите в [Issues](../../issues) и приложите журнал: «Настройки» → «Журнал» → «Открыть папку», файл `prism.log`.

## Режим для игр

Discord, включая голосовые каналы, работает и без этого режима. Режим «Игры» нужен для онлайн-игр, серверы которых тормозят или не открываются.

- Обходит только игровые серверы из полного списка подсетей Flowseal (`ipset-all.txt.backup`): это зарубежные хостинги и CDN, которые замедляют провайдеры. Остальной трафик игр не меняется.
- Не трогает сети издателей игр, лаунчеров и античитов: Riot, Valve, Blizzard, Roblox, EA, Epic Games, Ubisoft, Lesta, Nintendo, Krafton, Garena, Gaijin, Bungie, Supercell. Список в [`src-tauri/lists/ipset-exclude-games.txt`](src-tauri/lists/ipset-exclude-games.txt) собран из анонсов их автономных систем (RIPEstat). Домены Steam, Epic, Riot, Minecraft, Xbox и Lesta уже исключены в списках Flowseal.
- Правила для сайтов от режима не зависят, поэтому сайты он не затрагивает.
- Когда обход выключен, Prism выгружает драйвер WinDivert. Некоторые античиты не пускают в игру, пока он загружен.

Если какая-то игра не заходит с включённым обходом, напишите в [Issues](../../issues), какая именно.

## Из чего состоит

Prism — это только окно управления. Сам обход делают проверенные открытые программы:

| Часть | Откуда | Как попадает в сборку |
|---|---|---|
| Обход блокировок (winws.exe, WinDivert, стратегии) | [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) на основе [bol-van/zapret](https://github.com/bol-van/zapret) | Скачивается из официального релиза, хэши архива и winws.exe проверяются при каждой сборке |
| Прокси для Telegram | [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) | Собирается из исходников при каждой сборке |
| Адреса для нейросетей | [ImMALWARE/dns.malw.link](https://github.com/ImMALWARE/dns.malw.link) | Скачивается при включении режима, в файл hosts пишутся только разделы с нейросетями |

`.exe` собирает GitHub Actions из кода этого репозитория, вручную ничего не подкладывается. Хэши файлов лежат в `SHA256SUMS.txt` в каждом релизе.

## Обновления

- **Prism** проверяет новые версии в этом репозитории. Когда выходит новая, на главной появляется кнопка «Обновить»: установщик скачивается, проверяется по SHA-256 и ставится без вопросов, с одной полосой прогресса. После установки Prism запускается снова и включает то, что было включено. Портативная версия открывает страницу релиза.
- **Обходы** (winws.exe, WinDivert, стратегии, списки) обновляются сами при запуске из релизов [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube). Архив проверяется по SHA-256, который публикует GitHub. Перед заменой файлов Prism проверяет, что понимает стратегии новой версии: если нет, обновление откладывается до новой версии Prism, а обход продолжает работать. Если заменить файлы не получилось, обход снова запускается на прежней версии. Ваши списки сайтов сохраняются.
- **Адреса для нейросетей** обновляются при запуске, если режим включён. Если блок Prism пропал из файла hosts, он возвращается при следующем запуске.
- **Прокси для Telegram** обновляется вместе с новыми версиями Prism.

Автообновление можно выключить в «Настройки» → «Обновления».

## Частые вопросы

**Антивирус ругается на WinDivert или winws.exe.** Это ложная тревога, так антивирусы реагируют на любой zapret. Добавьте папку Prism в исключения.

**Режим «Нейросети» работает, даже когда Prism закрыт.** Он меняет файл hosts Windows. Prism пишет в него только свой блок и не трогает остальные записи, даже если файл сохранён не в UTF-8. Чтобы вернуть всё как было, выключите переключатель в Prism.

**Как работает автозапуск.** Prism создаёт задание «Prism» в планировщике Windows: оно запускает программу при входе в систему с правами администратора, поэтому окно UAC не появляется. Задание работает и от батареи ноутбука. Чтобы убрать автозапуск, выключите переключатель в Prism.

**Где настройки и журнал.** В `%LOCALAPPDATA%\io.github.lucudar.prism`: настройки в `settings.json`, журнал с датой и временем каждого события в `prism.log` (предыдущий в `prism.old.log`). Журнал также виден в «Настройках», там же кнопка «Открыть папку».
